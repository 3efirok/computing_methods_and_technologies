## 📌 Постановка задачі

У системах моніторингу комп'ютерних мереж та хмарних сервісів важливо оцінювати сумарне накопичене навантаження на сервер за добу $x \in [0, 24]$ годин.

Інтенсивність навантаження моделюється аналітичною функцією:
$$f(x) = 50 + 20 \sin\left(\frac{\pi x}{12}\right) + 5 e^{-0.2(x - 12)^2}, \quad x \in [0, 24]$$

Точне значення інтеграла:
$$I_0 = \int_0^{24} f(x) dx = 1200 + 5\sqrt{\frac{\pi}{0.2}} \operatorname{erf}(12\sqrt{0.2}) = 1200 + 5\sqrt{5\pi} \approx 1219.816636488029417$$

### Завдання:
1. Знайти аналітичний вираз точного значення інтеграла $I_0$.
2. Реалізувати складову формулу Сімпсона для обчислення означеного інтеграла при заданому парному числі розбиттів $N$.
3. Дослідити залежність похибки $\varepsilon(N) = |I(N) - I_0|$ від $N \in [10, 1000]$. Визначити оптимальне $N_{opt}$, при якому досягається точність $\varepsilon \le 10^{-12}$.
4. Обчислити похибку чисельного інтегрування при базовому числі розбиттів $N_0 = 24$ (кратне 8: $N_0/4 = 6$, $N_0/2 = 12$, $N_0 = 24$).
5. Уточнити значення інтеграла за методом Рунге-Ромберга при $N_0 = 24$ та $N_0/2 = 12$ ($p = 4$, знаменник $2^4 - 1 = 15$), обчислити похибку $\varepsilon_R$.
6. Уточнити значення за методом Ейткена для трійки розбиттів ($N_0/4 = 6$, $N_0/2 = 12$, $N_0 = 24$), визначити експериментальний порядок точності $p$ та похибку $\varepsilon_E$.
7. Проаналізувати результати порівняння точності для різних базових розбиттів $N_0 = 16, 24, 32$.
8. Реалізувати адаптивний алгоритм квадратури Сімпсона зі змінним кроком та дослідити залежність похибки й кількості викликів функції від допуску $\delta \in [10^{-2}, 10^{-12}]$.
9. Побудувати високоякісні графіки:
   - підінтегральної функції $f(x)$ та геометрії площі інтеграла;
   - збіжності складової формули Сімпсона (у подвійному логарифмічному масштабі);
   - порівняння похибок методів підвищення точності при базових вузлах $N_0$;
   - адаптивної нерівномірної сітки та локального розподілу кроку $h(x)$.
