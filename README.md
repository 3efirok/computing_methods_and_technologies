## 📁 Структура робіт

### 1. [Лабораторна робота №1: Інтерполяція кубічними сплайнами](Lab1/)
* **Тема:** Моделювання рельєфу трекінгового маршруту т/б «Заросляк» — гора Говерла.
* **Методи:** Природні кубічні сплайни ($C^2$-гладкість), метод прогонки (алгоритм Томаса), оцінка похибки для 10, 15, 20 вузлів, градієнтний аналіз та енерговитрати.
* **Звіти:** [Report_Lab1.docx](Lab1/Report_Lab1.docx), [Report_Lab1.pdf](Lab1/Report_Lab1.pdf).

### 2. [Лабораторна робота №2: Розділені різниці та многочлени Ньютона](Lab2/)
* **Тема:** Планування обчислювальних ресурсів (DevOps) — прогнозування навантаження на CPU залежно від RPS.
* **Методи:** Таблиці розділених та скінченних різниць, інтерполяційний многочлен Ньютона, факторіальні многочлени, дослідження точності та аналіз ефекту Рунге.
* **Звіти:** [Report_Lab2.docx](Lab2/Report_Lab2.docx), [Report_Lab2.pdf](Lab2/Report_Lab2.pdf).

### 3. [Лабораторна робота №3: Метод найменших квадратів (МНК)](Lab3/)
* **Тема:** Апроксимація температурних спостережень за 24 місяці та прогноз на наступні місяці.
* **Методи:** Метод найменших квадратів, розв'язання нормальної СЛАР методом Гауса з вибором головного елемента, дослідження дисперсії для степенів $m = 1 \dots 10$, оптимальний многочлен $m = 4$.
* **Звіти:** [Report_Lab3.docx](Lab3/Report_Lab3.docx), [Report_Lab3.pdf](Lab3/Report_Lab3.pdf).

### 4. [Лабораторна робота №4: Чисельне диференціювання](Lab4/)
* **Тема:** Точність формул для чисельного диференціювання на прикладі динаміки вологості ґрунту.
* **Методи:** Центральні різницеві формули ($O(h^2)$), регуляризація кроку сітки $h \in [10^{-20}, 10^3]$, метод Рунге-Ромберга, метод Ейткена та апостеріорна оцінка порядку точності.
* **Звіти:** [Report_Lab4.docx](Lab4/Report_Lab4.docx), [Report_Lab4.pdf](Lab4/Report_Lab4.pdf).

### 5. [Лабораторна робота №5: Чисельне інтегрування](Lab5/)
* **Тема:** Складова квадратурна формула для чисельного інтегрування. Методи підвищення точності. Адаптивний алгоритм (моделювання добового навантаження сервера $f(x)$).
* **Методи:** Складова квадратурна формула Сімпсона ($O(h^4)$), оптимальне число розбиттів $N_{opt} = 38$ ($\varepsilon \le 10^{-12}$), екстраполяція Рунге-Ромберга ($p = 4$, знаменник 15), прискорення збіжності Ейткена ($p \approx 3.82$), адаптивний алгоритм квадратури зі змінним кроком та локальним контролем точності.
* **Звіти:** [Report_Lab5.docx](Lab5/Report_Lab5.docx), [Report_Lab5.pdf](Lab5/Report_Lab5.pdf).

1. **Створення та активація віртуального середовища:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

2. **Встановлення необхідних залежностей:**
   ```bash
   pip install -r Lab1/requirements.txt
   ```

3. **Запуск будь-якої лабораторної роботи:**
   ```bash
   cd Lab1 && python main.py
   cd ../Lab2 && python lab2.py
   cd ../Lab3 && python main.py
   cd ../Lab4 && python main.py
   cd ../Lab5 && python main.py
   ```
