## 📐 Математична модель

1. **Розділені різниці:**
   - 0-й порядок: $f(x_i) = y_i$
   - 1-й порядок: $f(x_i, x_{i+1}) = \frac{f(x_{i+1}) - f(x_i)}{x_{i+1} - x_i}$
   - $k$-й порядок: $f(x_i, \dots, x_{i+k}) = \frac{f(x_{i+1}, \dots, x_{i+k}) - f(x_i, \dots, x_{i+k-1})}{x_{i+k} - x_i}$

2. **Многочлен Ньютона (інтерполяція вперед):**
   $$P_n(x) = f(x_0) + (x - x_0)f(x_0, x_1) + \dots + (x - x_0)\dots(x - x_{n-1})f(x_0, \dots, x_n)$$

3. **Факторіальні многочлени (для рівновіддалених вузлів):**
   $$P_n(x) = f_0 + t \frac{\Delta f_0}{1!} + t(t-1)\frac{\Delta^2 f_0}{2!} + \dots + t(t-1)\dots(t-n+1)\frac{\Delta^n f_0}{n!}, \quad t = \frac{x - x_0}{h}$$
